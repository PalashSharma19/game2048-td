# Read-only audit: which weights each agent actually uses

No training was run and no `.npz` file was read or written during this audit. The repository contains no `weights.npz`/`.npz` or `train_log.csv` according to the recursive file search. The earlier 50-game smoke output came from a mocked loader, not from a trained model; see answer 5.

## A. Networks used by `compare.py`

1. **The zero-weight agent uses a newly constructed `NTupleNetwork("small")`; the trained agent normally uses the object loaded from the `--weights` path, whose weights are read from the archive by `NTupleNetwork.load`.**

   `compare.py:66–73`

## Verdict

**Something else (explain).** The identical result was produced by the earlier smoke test’s mocked loader, which returned a fresh zero small network for the “Trained TD agent”; the run therefore compared two zero-weight policies. It did not test a real trained weights file. No `.npz` file is currently present in the repository, so the file’s nonzero count cannot be stated.

## Fix needed (not applied)

Run `compare.py` with the actual trained `.npz` path and without monkeypatching `NTupleNetwork.load`. Confirm the path exists and has nonzero weights. For future auditability, print and save each agent’s source path, network name, and weights shape at construction time.

## Other risk

`train.py` creates a new network unless `--resume` is supplied, then saves to `runs/<network>/weights.npz`; a training run can overwrite a file at that destination. No training was run for this audit.
